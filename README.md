# 온나에듀랩 공식 홈페이지 (시안)

놀러온나의 교육 브랜드 **온나에듀랩(ONNA EduLab)** 공식 홈페이지 시안입니다.
빌드 도구 없이 동작하는 정적 사이트로, GitHub Pages에 그대로 배포됩니다.

## 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 전체 페이지 (헤더 · 히어로 · 브랜드 소개 · 프로그램 · 온나 라이브 · 강점 · 출강 문의 · 푸터) |
| `styles.css` | 브랜드 컬러(`#3D5E9D` 메인 블루, `#4AB669` 포인트 그린) 기반 반응형 스타일 |
| `script.js` | 모바일 메뉴, 스크롤 등장 효과, 현재 섹션 표시 |
| `assets/logo.png` | 온나 에듀랩 공식 로고 (헤더·푸터·파비콘) |

## 로컬에서 보기

`index.html`을 브라우저로 열면 됩니다. 별도 서버가 필요 없습니다.

## 수정 시 참고

- 폰트: Noto Sans KR (Google Fonts)
- 학교별 수업 방 주소(`?room=...`)는 공개 페이지에 넣지 않습니다.
- 사업자 정보(상호·대표자·사업자등록번호·연락처·소재지)는 푸터에만 표기합니다.
